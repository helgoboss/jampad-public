== About this reference

The Jam Pad Reference complements the video tutorials with in-depth information that is better suited to written documentation. It covers key concepts as well as technical and specialized topics such as export formats, remote controls, and account management. It is not intended to document every screen, control, and feature of the app.

For a more practical, step-by-step introduction to Jam Pad, see the link:https://www.youtube.com/playlist?list=PLZb6yA75zPnI[tutorials].

== What is Jam Pad?

link:https://www.helgoboss.org/projects/jampad[Jam Pad] helps musicians organize recordings and the moments inside them. It is an offline-first, collaborative, and cross-platform app for recording, reviewing, and organizing audio.

=== Supported platforms

Jam Pad runs natively on the following platforms:

- Android phones and tablets
- iOS phones and tablets
- macOS computers
- Windows computers
- Linux computers
