= Key concepts

[[space]]
== Space

Spaces are the top-level organizational units in Jam Pad. A space is a self-contained collection of <<clip,clips>>, <<marker,markers>>, <<playlist,playlists>>, <<sheet,sheets>>, and other metadata.

Musicians will typically create at least one space for themselves and additional spaces for each band or musical project. Studios will typically create one space for each client or album.

[[single-device-space]]
=== Single-device space

All clips and other data in a single-device space stay on your device and your device only. You can create as many single-device spaces as you want.

Each space starts as a single-device space and can later be upgraded to a <<multi-device-space>> or <<cloud-space>>.

[[multi-device-space]]
=== Multi-device space

A multi-device space is synchronized directly between multiple devices, allowing you to conveniently access it from all of them, for example, from your mobile phone and your computer.

For this to work, you first need to configure one Jam Pad installation to act as the <<main-device, main device>> and then pair it with one or more <<companion-device,companion devices>>. For example, a computer makes a good main device, while a mobile phone makes a good companion device. After this one-time setup, you can upgrade arbitrary <<single-device-space,single-device spaces>> to multi-device spaces.

Small data (such as markers) in a multi-device space is seamlessly synchronized bidirectionally between your paired devices, so you can access it even when the devices are no longer connected. Large data (such as clips) is always synchronized to the <<main-device>>, ensuring that it eventually contains all of your clips. <<companion-device,Companion devices>> can selectively download clips from the main device, since companion devices typically have more limited storage.

The connection happens over your local Wi-Fi network and can optionally work over the internet as well. In both cases, your devices communicate using an end-to-end-encrypted peer-to-peer connection. Perfect for privacy!

TIP: When synchronizing over the internet, so-called link:https://en.wikipedia.org/wiki/Relay_network[relay servers] may help establish the initial connection between your devices. Even then, the servers cannot read your data.

NOTE: Multi-device synchronization is a paid feature.

[[cloud-space]]
=== Cloud space

A cloud space is a private space stored in the cloud and synchronized with arbitrary devices, allowing you and invited space members—and nobody else—to conveniently access it from anywhere.

For this to work, you first need to create a <<account,Jam Pad account>> and log in. After this one-time setup, you can upgrade arbitrary <<single-device-space,single-device spaces>> to cloud spaces.

All data in a cloud space is automatically synchronized to the cloud and, by default, is **only** accessible through your account. You can log in to the same account on your other devices, where the space will automatically appear and be ready to use.

Small data (such as markers) is seamlessly synchronized bidirectionally between your device and the cloud, so you can access it even when you go offline. Large data (such as clips) is always synchronized to the cloud. You can selectively download clips from the cloud to make them available offline as well.

Cloud spaces also come with collaborative features! You can invite other Jam Pad users to participate in your space—for example, members of your band or a client. They will see largely the same clips and data and can contribute by uploading their own clips, adding playlists, commenting, creating markers, and creating or editing <<sheet,sheets>>.
// It's also possible to send <<message,messages>> to your team, for example to start talking about certain musical passages or improvements.

[NOTE]
====
Creating and maintaining cloud spaces requires a paid subscription.
But: Invited space members can join without a subscription ❤️

Depending on your selected cloud plan, the following limits apply:

* Maximum number of participating users (across all of your own cloud spaces)
* Maximum storage space (across all of your own cloud spaces)
* Maximum number of owned cloud spaces

[[clip-id]]
==== Clip ID

A unique identifier for a clip. Even if you change the name or content of a clip, its ID always stays the same.

[[clip-version]]
==== Clip version

In theory, each clip in Jam Pad can have multiple versions, with each version referencing its own audio file.
In practice, this feature has not yet been fully implemented and is therefore only partially visible in the user interface.

[[asset]]
=== Asset

In Jam Pad, an asset is a larger file, such as an audio file (representing a clip version or an audio note) or a waveform peak file.

[[asset-id]]
==== Asset ID

Every asset in Jam Pad has a unique identifier. Most of the time, you won’t need to think about it, but if you explore the app more deeply, it’s useful to know what it represents.

An asset ID is an uppercase, 55-character string that may look cryptic at first. It is actually a checksum of the asset’s content. This means that two assets with identical content will always produce the same ID. As a result, Jam Pad automatically avoids duplicates within a space, helping you save storage.

[[device-sync]]
== Device sync

A method of synchronizing spaces directly between devices (peer-to-peer) without storing anything in the cloud.
It can happen either via a local network ("Wi-Fi Sync") or over the internet ("Remote Sync").

[[main-device]]
=== Main device

The leading synchronization device in a <<device-sync>> setup. It can be paired with multiple companion devices.
There can be only one main device in a device-sync network. Computers are recommended for this role.

[[companion-device]]
=== Companion device

A secondary synchronization device in a <<device-sync>> setup. Each companion device connects to a particular
main device, from which it can stream and selectively synchronize clips. Mobile devices are recommended for this role.

[[cloud-sync]]
== Cloud synchronization

A method of synchronizing spaces via the Jam Pad Cloud. It requires an account and internet access. It also enables
collaboration.

[[account]]
=== Account

A Jam Pad user account is necessary if you want to:

* sync <<in-app-purchase,in-app purchases>> across multiple devices
* use <<cloud-sync>>
